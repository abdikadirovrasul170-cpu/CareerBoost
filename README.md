# CareerBoost

**CareerBoost** — Java 21 және Spring Boot негізіндегі мансаптық портал. Жүйе пайдаланушыларға профиль жүргізуге, түйіндеме (резюме) құруға және бос жұмыс орындарын қарауға мүмкіндік береді.

## Технологиялар
- Java 21
- Spring Boot 3.5
- Maven
- Spring Web, Thymeleaf
- Spring Data JPA, H2 Database
- Jakarta Bean Validation

## Жобаны іске қосу
1. Java 21 орнатыңыз.
2. Репозиторийді көшіріңіз: `git clone https://github.com/abdikadirovrasul170-cpu/CareerBoost.git`
3. Жоба бумасына өтіңіз: `cd CareerBoost`
4. Қосымшаны іске қосыңыз: `mvn spring-boot:run`
5. Браузерден ашыңыз: http://localhost:8080

## MVP мүмкіндіктері
- Тіркелу және жүйеге кіру
- Пайдаланушы профилі
- Резюме құру, сақтау және өңдеу
- Резюме үлгілерін таңдау
- Бос жұмыс орындарын қарау

## Кейінгі мүмкіндіктер
PDF экспорты, резюмені бағалау, жұмысқа өтінім беру, әкімші панелі және жобалау паттерндерін қолдану.
