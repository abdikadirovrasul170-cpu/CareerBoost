# GitHub Milestones және Projects тақтасын баптау

Бұл құжат GitHub Milestones пен Projects тақтасын жоспарлау және тапсырмаларды ұйымдастыру тәртібін сипаттайды. Қазіргі GitHub байланысында Issue және файл жасау/өзгерту қолжетімді, бірақ Milestone және Projects тақтасын тікелей жасау әрекеттері берілмеген. Сондықтан төмендегі екі баптауды GitHub сайтында қолмен орындау қажет.

Репозиторий: https://github.com/abdikadirovrasul170-cpu/CareerBoost

## 1. MVP milestone жасау
1. Репозиторийді ашыңыз.
2. **Issues → Milestones → New milestone** таңдаңыз.
3. Title: `MVP`
4. Description: `Негізгі жұмыс істейтін нұсқа: тіркелу/кіру, профиль, резюме құру және өңдеу, үлгі таңдау, бос жұмыс орындарын қарау.`
5. Due date ретінде оқытушы белгілеген мерзімді енгізіңіз (мерзім белгісіз болса, бос қалдырыңыз).
6. **Create milestone** басыңыз.

MVP кезеңіне Issue #1–#10 міндеттерін қосыңыз: жобаны дайындау, Maven/дерекқор конфигурациясы, User моделі, тіркелу, кіру, профиль, Resume Builder, резюмені өңдеу және үлгілер.

## 2. Final milestone жасау
1. Қайтадан **Issues → Milestones → New milestone** таңдаңыз.
2. Title: `Final`
3. Description: `Қорытынды нұсқа: бос жұмыс орындары, PDF экспорты, резюмені бағалау, қосымша паттерндер, автоматты тесттер және құжаттаманы аяқтау.`
4. **Create milestone** басыңыз.

Final кезеңіне Issue #11–#15 міндеттерін қосыңыз: жұмыс орындары, PDF экспорты, Strategy, Adapter/Visitor және автоматты тесттер/құжаттама.

Әр Issue ішінен оң жақтағы **Milestone** өрісінен тиісті кезеңді таңдауға болады.

## 3. GitHub Projects тақтасын жасау
1. Репозиторийдегі **Projects** қойындысын ашыңыз.
2. **New project** таңдаңыз.
3. **Board** үлгісін таңдаңыз.
4. Атауы: `CareerBoost Development Board`.
5. Кемінде мына бағандарды пайдаланыңыз: `Todo`, `In Progress`, `Review`, `Done`.
6. **Add item** арқылы CareerBoost репозиторийіндегі Issue #1–#15 тапсырмаларын тақтаға қосыңыз.
7. Қажет болса, Status өрісін осы төрт бағанға сәйкестендіріңіз.

## 4. Тапсырмаларды орындау реті
- Алдымен MVP milestone ішіндегі міндеттерді орындаңыз.
- Әр тапсырманы бастағанда Issue күйін `In Progress` етіңіз.
- Кодты тексеріп, commit жасағаннан кейін `Review` немесе `Done` күйіне ауыстырыңыз.
- MVP аяқталған соң Final milestone міндеттеріне көшіңіз.

## 5. Терминалдан жобаны іске қосу
VS Code → Terminal → New Terminal:
```bash
mvn spring-boot:run
```

Қосымша браузер ашпай іске қосылады. Builder, Abstract Factory, Template Method, Strategy, Adapter және Visitor демонстрациялары VS Code терминалында көрсетіледі.

Ескерту: іске қосу үшін JDK 21 және Maven орнатылған болуы керек.
