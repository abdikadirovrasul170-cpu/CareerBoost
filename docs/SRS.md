# CareerBoost — Software Requirements Specification (SRS)

## 1. Кіріспе
CareerBoost — жұмыс іздеушілерге кәсіби профиль құруға, резюме дайындауға және бос жұмыс орындарын табуға көмектесетін веб-қосымша.

## 2. Мақсаты
Резюме дайындау процесін жеңілдету және жұмыс іздеу ақпаратын бір платформада ұсыну.

## 3. Пайдаланушылар
- Жұмыс іздеуші: профиль мен резюме жасайды, вакансияларды қарайды.
- Әкімші: пайдаланушылар мен вакансиялар мазмұнын басқарады (кейінгі кезең).

## 4. Функционалдық талаптар
- FR-01: пайдаланушы тіркеле алады.
- FR-02: пайдаланушы жүйеге кіріп, жүйеден шыға алады.
- FR-03: пайдаланушы жеке профилін көріп, өңдей алады.
- FR-04: пайдаланушы жаңа резюме жасай алады.
- FR-05: резюмеге білім туралы ақпарат қоса алады.
- FR-06: резюмеге жұмыс тәжірибесін қоса алады.
- FR-07: пайдаланушы резюмесін сақтап, кейін өңдей алады.
- FR-08: пайдаланушы резюме үлгісін таңдай алады.
- FR-09: пайдаланушы бос жұмыс орындарының тізімін көре алады.
- FR-10: пайдаланушы вакансияларды атауы немесе санаты бойынша іздей алады.
- FR-11: пайдаланушы вакансияға өтінім бере алады.
- FR-12: пайдаланушы резюмені PDF форматына экспорттай алады.
- FR-13: жүйе резюме сапасын бағалау бойынша ұсыныстар бере алады.

## 5. Функционалдық емес талаптар
- NFR-01: интерфейс түсінікті және қазақ/орыс тілдеріндегі мәтінді көрсетуге жарамды болуы керек.
- NFR-02: деректер валидациядан өтуі керек.
- NFR-03: парольдер ашық мәтін түрінде сақталмауы керек.
- NFR-04: деректер қорының құрылымы кеңейтуге қолайлы болуы керек.
- NFR-05: негізгі бет заманауи браузерлерде жұмыс істеуі керек.
- NFR-06: қателер пайдаланушыға түсінікті түрде көрсетілуі керек.
- NFR-07: код модульдерге бөлініп, тестілеуге жарамды болуы керек.
- NFR-08: құпия деректер қорғалуы керек.

## 6. MVP шекарасы
MVP құрамына тіркелу/кіру, профиль, резюме құру/өңдеу, резюме үлгілері және вакансиялар тізімі кіреді.

## 7. Кейінгі нұсқа
PDF экспорты, резюме сапасын бағалау, вакансияға өтінім беру, әкімші панелі және қосымша қауіпсіздік мүмкіндіктері кейінгі кезеңде іске асырылады.

## 8. Технологиялық стек
Java 21, Spring Boot, Maven, Thymeleaf, Spring Data JPA, H2 Database және Jakarta Validation.
