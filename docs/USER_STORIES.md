# CareerBoost — User Stories

1. **Тіркелу:** Жұмыс іздеуші ретінде жүйеге тіркелгім келеді, себебі жеке кабинетімді пайдалануым керек.
2. **Жүйеге кіру:** Тіркелген пайдаланушы ретінде аккаунтыма кіргім келеді, себебі деректеріме қол жеткізуім керек.
3. **Профиль:** Пайдаланушы ретінде жеке ақпаратымды толтырып, өңдегім келеді.
4. **Резюме құру:** Жұмыс іздеуші ретінде жаңа резюме жасағым келеді.
5. **Білім:** Резюмеме оқу орны, мамандық және оқу жылдарын қосуды қалаймын.
6. **Жұмыс тәжірибесі:** Резюмеме бұрынғы жұмыс орындары мен міндеттерімді енгізгім келеді.
7. **Резюмені өңдеу:** Сақталған резюмемді жаңартқым келеді.
8. **Үлгі таңдау:** Резюмемнің дизайнын дайын үлгілердің ішінен таңдағым келеді.
9. **PDF экспорт:** Резюмемді PDF ретінде жүктеп алғым келеді.
10. **Вакансияларды қарау:** Жұмыс іздеуші ретінде қолжетімді вакансияларды көргім келеді.
11. **Іздеу:** Вакансияларды атауы немесе санаты бойынша іздегім келеді.
12. **Өтінім беру:** Таңдаған вакансияма резюме арқылы өтінім жібергім келеді.
